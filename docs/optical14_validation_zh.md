# 14 种算子：实现、可视化与验证记录

本次保留原有 14 个 ID，通过 `optical_marker_v1` 显式启用新实现。
旧 registry、旧模型配置和已有评测结果不自动改动。
本页是工程与数据处理证据，不是新的闭环成功率或真实硬件损坏验证。

## 核心设计

可视化直接展示正式 `apply_fault` / `StreamingFaultSession` 的输出，
没有一套单独为画图美化的扰动算法。原始图、Delivered 和差分分别保存；
缺失 payload 显示为缺失，不伪造一张黑色触觉图。

| 类别 | 设计与可验证含义 |
|---|---|
| A1 / A2 | 连续缺失 / 间歇丢帧；用真实 presence 时序区分 |
| F1 | 通道相关的增益、偏置随时间漂移；不做几何位移 |
| F2 | 中心局部光学响应衰减；mask 外逐像素不变 |
| F3 | 持续的局部表面外观条纹；实时接触仍在更新 |
| F4 | 边缘区域的光学响应退回参考场；不粘贴第二套 marker |
| F5 | 当前帧一致的局部形变；接触与 marker 一起受同一个映射作用 |
| F6 | 同一序列的光学响应快速建立、缓慢恢复；只有当前 marker |
| F7 | 相对参考场的光学响应软饱和；不把 RGB 强度当作压力 |
| T1 / T2 / T3 | 双流共同延迟 / 末帧保持后恢复 / 单侧延迟产生左右时间差 |
| C1 / C2 | 左右完整来源交换 / 注册坐标平移；不声称重新安装了传感器 |

F2/F4/F6/F7 使用“光学场＋当前 marker”的分解：先估计 marker 遮挡下的
局部光学场，处理其相对参考场的响应，再原样保留当前 marker 像素。
这是显式的光学观测代理，不是从 RGB 恢复真实三维形变或材料力学。
F5 的语义不同：既然做一致的图像形变，marker 应随同一映射变化。

## 看图后发现并解决的问题

1. **错误参考帧比算子强度更关键。** 原来的 key55、HDMI90 “低变化参考帧”
   都已经握住物体，不能当成无接触。与这些帧混合会引入历史物体轮廓。
   现在改为官方 Taxim 标定资源生成的零压入光学参考场，明确标注它不是
   实际拍到的无接触帧。
2. **用原始深度验证参考。** 官方渲染器重渲染 recorded depth，与原始
   marker-free RGB 比较；最终独立复现输入有 16 组对照，MAE 为
   0.9484–1.2957/255。34 mm 与 40 mm 的远离平面输入产生相同零压入场。
   这支持渲染路径一致性，但不能单独证明材料物理真实性。
3. **不把局部卸载叫完全 release。** F6 使用 key55 左侧连续 105–107 帧，
   原始深度证实一部分表面离开接触范围；物体仍被夹持。它展示局部历史
   残痕，不能代表一次完整脱离后数秒恢复的案例。
4. **原始样例决定可见程度。** F2 固定中心 mask，在 key 样例中变化很弱；
   改用 HDMI 的固定 clean 帧展示中心附近的接触边缘。初次换样例仍较弱，
   进一步把强作用核心/外支撑半径从图像短边的 0.10/0.20 调整为
   0.16/0.28，中心不变；S1–S5 保留响应为 90%、75%、55%、30%、10%。
   这些是明确公开的工程参数，未用模型成功率调参。F4 继续使用 key 边缘。
5. **时间算子必须看时序。** T1 双侧都落后；T3 只有一侧落后；T2 在
   delivery 时间推进时保持同一源帧，然后恢复新源帧。不能用单张图解释。

## 证据边界与下一道门槛

v6 阶段验证记录：14 个算子实例、F2/F4/F6/F7 的 20 个 S1–S5 实例全部通过；
47 个输出文件 hash 和 84 个生产代码/schema hash 回读一致。
局部回归为 82 tests、427 subtests 通过；主运行路径 Ruff、strict mypy 通过。

下表是**相同固定 clean 帧上的全图平均绝对像素差**，单位为 0–255 原始
像素值，不是压力、受损百分比或成功率。局部区域只占全图一部分，因此
不能仅依据数值小就判断算子没有生效；必须结合 mask、原图与时序查看。

| 算子 | S1 | S2 | S3 | S4 | S5 |
|---|---:|---:|---:|---:|---:|
| F2 | 0.0805 | 0.2216 | 0.4038 | 0.6420 | 0.8314 |
| F4 | 0.5433 | 0.5998 | 0.6795 | 0.7708 | 0.8909 |
| F6 | 0.1279 | 0.3662 | 0.8248 | 1.5830 | 2.5034 |
| F7 | 0.0862 | 0.2620 | 0.6354 | 1.0875 | 1.7033 |

- 原始输入来自真实存在的 UniVTAC 记录文件，但这些记录本身是仿真数据，
  不是真实机器人传感器采集。
- 没有大模型生成图片。扰动图是确定性代码处理结果；零压入参考来自
  官方光学渲染器，而不是伪称原始记录中的无接触样本。
- source、参数、运行时输出及图像都有 SHA256；展示帧在扰动前固定。
- 测试覆盖实现一致性、当前 marker、mask 外不变、因果历史、时钟、旧版本
  回归等；差分随 severity 增大不等于物理损伤程度已经标定。
- 当前仍为 G1 光学故障代理。要提升同行对物理真实性的信任，下一步应
  用真实传感器的无接触、压入、保持、完整释放数据拟合/验证这些参数，
  特别是 F6 恢复时间与 F7 响应饱和，而不是靠持续加大图像效果。
